# Package index

## Funciones

Las tres piezas del paquete, de los datos crudos al gráfico.

- [`descargar_estacion()`](https://maipochettino.github.io/lloRando/reference/descargar_estacion.md)
  : Descargar y leer los datos de una estación
- [`tabla_resumen_temperatura()`](https://maipochettino.github.io/lloRando/reference/tabla_resumen_temperatura.md)
  : Resumir la temperatura por estación
- [`grafico_temperatura_mensual()`](https://maipochettino.github.io/lloRando/reference/grafico_temperatura_mensual.md)
  : Graficar la temperatura media mensual

## Datos

Listos para usar, sin descargar nada.

- [`estaciones`](https://maipochettino.github.io/lloRando/reference/estaciones.md)
  : Datos diarios de cinco estaciones del INTA
- [`estacion_completo`](https://maipochettino.github.io/lloRando/reference/estacion_completo.md)
  : Datos meteorológicos de estaciones
- [`metadatos`](https://maipochettino.github.io/lloRando/reference/metadatos.md)
  : Metadatos de estaciones meteorológicas
