# Datos diarios de cinco estaciones del INTA

Observaciones meteorologicas diarias de las estaciones NH0046, NH0098,
NH0437, NH0472 y NH0910.

## Usage

``` r
estaciones
```

## Format

Un data frame con una fila por estacion y dia. Columnas principales:

- id:

  Identificador de la estacion.

- fecha:

  Fecha de la observacion.

- temperatura_abrigo_150cm:

  Temperatura media a 150 cm (grados C).
